# Previous ShikshaSetu template restored

The project now uses the original paired theme from the earlier ShikshaSetu screenshots:

- **Light mode:** deep forest photographic canvas, bright botanical/aqua glass on cards, pale translucent sidebar and topbar, dark readable text inside panels, luminous soft-green glass rims.
- **Dark mode:** deeper forest canvas, dark emerald translucent cards, brighter moss/grass edge light, white typography and high-contrast table rows.

The same pairing is applied to the login/account-creation page. Tables retain theme-aware headers, rows, separators, hover state and scroll frame. The 24-scene background rotation remains enabled and now uses the active theme's correct overlay during both static display and crossfade.

No routes, backend source, AI model logic, data schemas, workspace sections or controls were intentionally removed.

## Verification

JavaScript syntax, CSS parse, HTML duplicate IDs, local asset paths, 24 gallery files, and ZIP integrity were checked. Maven compilation and interactive browser testing remain environment-dependent; the Java backend was not compiled in this environment.
